# Optimization

## FX Modules (Lazy Loading)

Location: `resources/scripts/3rd/fx/[component]/`

| Selector             | Component  |
| -------------------- | ---------- |
| `data-fx-accordion`  | accordion  |
| `data-fx-counter`    | counter    |
| `data-fx-dropdown`   | dropdown   |
| `data-fx-lightbox`   | lightbox   |
| `data-fx-offcanvas`  | offcanvas  |
| `data-fx-scroll-top` | scroll-top |
| `data-fx-slider`     | slider     |
| `data-fx-tabs`       | tabs       |

Scripts: `defer`/`module` via `HD\Core\Optimizer\ScriptLoader`
